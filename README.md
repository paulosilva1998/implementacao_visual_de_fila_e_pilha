# Uma página com HTML + CSS + JavaScript: 

1. Criei um formulário com 1 input e 5 botões de ação

    ✅ Inserir no início;

    ✅ Inserir no fim;

    ✅ Excluir no início;

    ✅ Excluir no fim;

    ✅ Buscar elemento;

2. Apliquei CSS para visualizar a Lista de itens

3. Implementei a rotina de inserir no início;

4. Implementei a rotina de inserir no fim;

5. Implementei a rotina de excluir no início;

6. Implementei a rotina de excluir no fim;

7. Implementei a rotina de identificar um elemento (ao pesquisar um número destaque ele na lista, se existir)
